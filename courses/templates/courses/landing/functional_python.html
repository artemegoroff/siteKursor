Выбери пример и проследи, как меняется результат на каждом шаге. Эти приёмы разберём на курсе.

transform.py
def is_even(number):
    return number % 2 == 0

def square(number):
    return number ** 2

data = [1, 2, 3, 4, 5, 6]
evens = filter(is_even, data)
result = list(map(square, evens))
Входные данные[1, 2, 3, 4, 5, 6]
↓
filter → чётные[2, 4, 6]
↓
map → квадрат числа[4, 16, 36]

filter выбирает элементы, map применяет функцию. Исходный список остаётся прежним.
