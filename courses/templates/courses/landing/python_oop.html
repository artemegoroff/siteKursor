Понять объект.

Класс описывает устройство и поведение. Экземпляр хранит своё состояние. Метод работает с конкретным объектом через self.

Пример справа — реализация класса Task из интерактивной схемы. На курсе разберём, что происходит в каждой строке.

task.py
class Task:
    def __init__(self, title):
        self.title = title
        self.done = False

    def complete(self):
        self.done = True
