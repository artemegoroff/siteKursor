# Главная страница и поиск

Главная помогает выбрать курс или сразу найти объяснение. Первый экран содержит рабочий поиск, далее — карточки лендингов, другие учебные направления, маршрут старта, библиотека, форматы «вся теория на сайте / полный курс с практикой на Stepik», автор и экзамены.

Шаблоны: `home/home_page.html`, `home/search.html`, база `home/base.html`. Оформление — `base_static/css/home.css`. Для этих двух страниц не подключаются старые Bootstrap/LESS, jQuery и плагины каруселей; остальные страницы продолжают использовать прежнюю базу. Блоки базового шаблона позволяют отключить эти зависимости без изменения уроков и экзаменов. Шапка и её нативные disclosures остаются общими.

Карточки лендингов берутся из LANDING_COURSES. Ссылка на теорию ищет совпадение с существующим LearningCourse по Stepik ID, затем по явно заданным названиям/slug. Если совпадения нет, показывается «Каталог уроков», а не несуществующая страница курса. Другие направления и раздел «Уроки» отображают текущие курсы с непустым slug и хотя бы одним уроком. Пустые служебные курсы, созданные исторической миграцией, не рекламируются. Полученный каталог кешируется в рамках одного запроса и используется также меню; количество запросов не растёт с количеством карточек. Порядок задаётся через sort_order курсов.

Поиск `/search/?q=...` работает по названиям курса, модуля и урока, заголовкам блоков и содержимому текстовых блоков. Это поиск без отдельного сервиса: ORM icontains, до 120 символов и 8 слов, совпадение всех слов, 12 результатов на страницу. Есть путь курс/модуль, фрагмент объяснения, пустое состояние и пагинация. Дубли результатов от нескольких блоков исключены. Вход и выдержки экранируются; произвольный HTML или JavaScript не исполняются. Страницы поиска имеют noindex,follow. Пользовательский поиск не требует JS.

Прежние videos-ссылки удалены из меню, главной и sitemap. История миграций videos остаётся для courses.0002; таблицы удаляются миграцией videos.0025 после сохранения соответствий старых адресов. См. `docs/retire-videos.md`.

Проверено: 42 тест Django courses/home, создание базы с нуля, обновление исторической базы с архивными уроками, сохранение изменённых блоков, редиректы и новый sitemap с разреженными номерами экзаменационных заданий. Chromium 1440/1024/768/390/320 — без горизонтальной прокрутки и ошибок JS, поиск и переход к уроку; отправка формы без JS. Браузерная проверка использует отдельную SQLite-базу с тестовыми курсами, рабочая база не изменялась.

Выпуск: сохранить дамп, проверить обновление на его копии MySQL, остановить старые воркеры, обновить код, выполнить `python manage.py migrate`, `python manage.py collectstatic --noinput`, перезапустить приложение. Удаление архивных таблиц не восстанавливает их данные при обратной миграции; для отката нужен дамп. Новые зависимости не добавлялись.
