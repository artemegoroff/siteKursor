Промостраница проверена 27 ноября 2026. Подробная программа в доступном представлении страницы не загрузилась. Повторные запросы страницы, syllabus и API результата не дали; прямой браузерный доступ завершился сетевой ошибкой. Поэтому лендинг не содержит выдуманного перечня модулей. Блок с представлением и HTTP-ответом — самостоятельная учебная иллюстрация принципа работы веб-приложения, а не обещание точного состава уроков. Чтобы добавить подробную программу, нужны подтверждённые названия разделов от автора или доступный ответ Stepik.

Уровень: знакомство с Django после Python и ООП. Обозначения «3 ступень» и «Middle+» из визуального референса не перенесены. Дизайн использует голубой цвет, диагональные линии, светлый макет браузера, розовые и жёлтые акценты. Сторонний персонаж не копируется. Название курса сохранено.

Вся теория бесплатно доступна на сайте. Полный курс с видео, тестами и практикой — на Stepik. Существующий учебный курс ищется через общий каталог по идентификатору 114288 в ссылке Stepik или алиасу django; если записи нет, ссылка ведёт в библиотеку с пояснением. Никакие записи или URL уроков не создаются и не меняются.

## Реализация

Контент: `courses/django_landing_data.py`; шаблон, CSS и JS отдельные. Общий реестр автоматически добавляет лендинг на главную, в меню и sitemap. Карточка располагается после ООП. На главной добавлен маршрут «Выходи в веб».

В примере можно переключить `/hello/` и `/about/`: меняются функция, код запроса и ответ. Используется только фиксированная модель браузера: нет Python-интерпретатора, запросов к серверу и сохранения прогресса. Выбранный вариант обозначен aria-pressed; ответ объявляется через aria-live. Без JavaScript остаются исходный пример, все ссылки и раскрывающиеся разделы, кнопки переключения отключены.
