# Функциональное программирование на Python

Адрес: `/learn/functional-python/`. Собственный дизайн, шаблон `courses/landing/functional_python.html`, CSS и JS `base_static/{css,js}/landing/functional-python.*`. Конфигурация в `courses/functional_landing_data.py`; общий реестр выбирает шаблон и метаданные отдельно для каждого курса. Страница Инди-курса сохраняет своё оформление.

Источник данных: https://stepik.org/course/195619/promo (читаемая версия https://stepik.org/course/195619/promo?auth=login), проверено 17 ноября 2026. Девять модулей соответствуют опубликованной программе; пояснения написаны для лендинга. Счётчики платформы: 46 уроков, 223 задачи, 336 тестов; описание промо содержит другие числа (230/340), поэтому взяты счётчики. Рейтинг 4,9 по 465 отзывам. Цена 1499 ₽ показана с датой, ссылка на актуальные условия находится рядом. При изменении данных обновляйте конфигурацию и дату проверки вместе.

Требования, Telegram-чат, бессрочный доступ и сертификат подтверждены промостраницей. Оплата и обучение происходят на Stepik. Цитаты отзывов, сроки ответа поддержки и гарантии трудоустройства не добавлялись. Портрет используется из уже опубликованного лендинга автора.

Лаборатория — три фиксированных примера с переключением исходного кода и промежуточных результатов. Это иллюстрация, не интерпретатор. Произвольный код не принимается и не исполняется. Без JavaScript показан первый пример, доступны программа, FAQ и основные ссылки. На мобильном меню закрывается после выбора ссылки и по Escape; предусмотрены видимый фокус и reduced motion.

Ссылки добавлены в меню Python и карточку на главной. Sitemap берёт новые адреса из общего реестра. JSON-LD содержит Intermediate и isAccessibleForFree=false для платного курса; у базового курса сохранены Beginner и true.

Развёртывание: обычный `python manage.py collectstatic --noinput`; миграции и дополнительные пакеты не нужны. Проверки: тесты приложения courses, Chromium 1440/1024/768/390/320 px, лаборатория, программа/FAQ, мобильное меню/Escape, загрузка портрета, просмотр без JavaScript. Браузерный скрипт использовался как локальная проверка и не является зависимостью проекта.
