# Переход с videos на courses

Меню, карточки главной и sitemap используют LearningCourse, LearningModule и
Lesson. Счётчики на главной считают уроки, включая подуроки, а не видеоблоки.
Новые курсы автоматически появляются в меню и на главной; пустой slug исключён.

## Что удаляется

Удаляются рабочие модели Course, ProgrammTask и InputOutputData из videos,
их админка, обработчики, шаблоны и старые скрипты плеера/меню. Миграция
videos.0025 удаляет соответствующие таблицы и промежуточные таблицы связей.
Архивные практические задачи не преобразуются в LessonBlock и удаляются.
Материалы courses и данные ЕГЭ/ОГЭ остаются.

Каталог videos теперь содержит только служебную конфигурацию и историю миграций.
Он необходим: courses.0002 обращается к исторической модели videos.Course.
Простое удаление videos из INSTALLED_APPS нарушит граф миграций, в том числе
при создании базы с нуля. Исполняемых моделей videos больше нет.

## Старые ссылки

courses.0008 создаёт таблицу LegacyCourseRedirect. courses.0009 читает архивные
уроки и сохраняет соответствия по slug и номеру до запуска videos.0025.
Пути /old_course/ и /course/ возвращают постоянный редирект в каталог.
Сохранённые ссылки на курс или урок перенаправляются на его актуальный адрес.
Перенос урока в другой модуль и последующая смена slug не ломают редирект.

Если уникальное соответствие урока не найдено, ссылка ведёт на соответствующий
курс, а если курс неизвестен — в каталог. Миграция сообщает число таких случаев.
При необходимости соответствия можно исправить в админке курсов.
Неизвестные адреса и старые страницы разборов задач возвращают 404.

## Выпуск

1. Сохранить свежий дамп рабочей базы и проверить успешное завершение экспорта.
2. Проверить обновление на локальной копии MySQL, восстановленной из этого дампа.
3. На сервере остановить старые воркеры или включить режим обслуживания: старый
   код после удаления таблиц videos работать не сможет.
4. Установить код и зависимости, выполнить:

   ```sh
   python manage.py check
   python manage.py migrate --plan
   python manage.py migrate
   python manage.py collectstatic --noinput
   ```

   План должен сохранять редиректы courses.0009 до удаления таблиц videos.0025.
5. Перезапустить приложение способом, принятым на хостинге, и проверить главную,
   меню, sitemap.xml, уроки/подуроки и несколько старых ссылок.

Откат DeleteModel создаст пустые архивные таблицы, но не восстановит их строки.
Для восстановления старой версии с данными нужен сохранённый дамп и старый код.
Не удалять исторические миграции и не запускать migrate --fake.

## Проверки

```sh
python manage.py test courses
python manage.py makemigrations --check --dry-run
```

Тесты покрывают динамическое меню/главную, количество запросов, sitemap с
разреженными номерами заданий, старые ссылки и обновление базы до и после
первоначального переноса архивных уроков.
