# Лендинг Инди-курса Python

Адрес: `/learn/python/`. Ссылки добавлены в меню Python и первую карточку главной страницы. Библиотека уроков продолжает работать по прежним адресам.

Содержание: `courses/landing_data.py`; шаблон: `courses/templates/courses/landing/python.html`; оформление и поведение: `base_static/css/landing/python.css` и `base_static/js/landing/python.js`. Для другого курса нужно подготовить собственные тексты и шаблон, затем добавить конфигурацию и выбор шаблона во view.

Источник: https://stepik.org/course/63085/promo, проверено 17 ноября 2026. В индексируемой версии: 73 урока, 434 задачи, 548 тестов, рейтинг 4,9, 2609 отзывов, 226319 учащихся. На странице использованы нижние округлённые границы; обновляйте конфигурацию и дату проверки вместе. Семь разделов программы — тематический обзор, не точное воспроизведение модулей Stepik. Цитаты отзывов не добавлены; ссылка ведёт к источнику. Условия сертификата нужно смотреть на Stepik.

Пример на первом экране показывает две фиксированные строки Python: JavaScript подставляет имя через textContent. Это демонстрация, не интерпретатор Python. Никакой пользовательский код не исполняется. Без JavaScript основное содержание, ссылки, программа и FAQ доступны; кнопка примера отключена.

Миграции и новые зависимости не нужны. При развёртывании выполните обычный `python manage.py collectstatic --noinput`.

Проверка: Django tests `courses`, ширины 1440/1024/390/320, ввод имени и Enter, мобильное меню/Escape, раскрытие программы и FAQ, плавающая кнопка на мобильном. Страница содержит canonical без query-параметров и JSON-LD Course; маршрут добавлен в sitemap. Существующий глобальный обработчик 404 проекта возвращает 200 — это прежнее поведение сайта; view лендинга корректно поднимает Http404 для неизвестного курса.
