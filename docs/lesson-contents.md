# Автоматическое оглавление урока

На широком экране (от 1200 px) оглавление располагается справа и остаётся
на экране при прокрутке. На телефонах и планшетах это раскрывающийся блок
«Содержание урока» под названием. После выбора пункта он сворачивается.
Если найдено меньше трёх пунктов, панель не показывается.

## Подготовка текста

В TinyMCE оформлять разделы как «Заголовок 2», подразделы — «Заголовок 3».
Жирный текст не считается заголовком. Название урока остаётся h1.
Заголовки текстовых блоков, видео, практики и раздела подуроков учитываются
автоматически. Повтор названия текстового блока в первом заголовке его текста
показывается в оглавлении одним пунктом; сам текст не изменяется.

## Якоря и ссылки

Якоря добавляются в DOM страницы; база данных и сохранённый HTML не меняются.
Для русского текста используется транслитерация, для английского — обычный
slug. Повторы получают суффиксы -2, -3 и далее. Существующие уникальные id
сохраняются; дублирующиеся id заголовков исправляются, чтобы ссылки работали.
Также учитываются id других элементов страницы, чтобы не перезаписать их.

Ссылку на раздел можно скопировать из оглавления или адресной строки после
перехода. Автоматический якорь стабилен, пока название и порядок одинаковых
заголовков не меняются. Для важных постоянных ссылок можно задать id вручную.

Оглавление подсвечивает текущий раздел, но не меняет URL при обычном чтении.
История браузера обновляется только по явному выбору пункта. Переход учитывает
закреплённую шапку, переносит клавиатурный фокус на заголовок и отключает
плавную прокрутку при prefers-reduced-motion. Без JavaScript материал остаётся
доступен в прежней одноколоночной вёрстке, оглавление скрыто.

## Установка

Миграции и новые зависимости не требуются. После обновления кода выполнить
collectstatic, если сервер использует собранную статику, и обновить страницу.
Изменён также navbarBoot4.less: последнее выпадающее меню на компьютере
выравнивается по правому краю, чтобы не создавать горизонтальную прокрутку.

## Проверка

- h2/h3 в тексте, заголовки видео и практики, повторяющиеся названия.
- Существующие якоря и совпадения с id других элементов.
- Открытие страницы сразу с #якорем и кнопка «Назад» после переходов.
- Подсветка при прокрутке, длинное оглавление со своей полосой прокрутки.
- Телефон, планшет, смена размера окна и закрытие после выбора раздела.
- Урок с двумя заголовками и страница без JavaScript.
- Клавиатурный фокус, Ctrl/Cmd-click и настройка уменьшенной анимации.
