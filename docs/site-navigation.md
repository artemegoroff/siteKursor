# Главное меню сайта

Старое меню ClassyNav задавало ссылкам height:35px и line-height:34px. Название функционального курса переносилось и перекрывало соседние пункты. Новый компонент не использует классы ClassyNav и фиксированную высоту текстовых блоков.

Структура: «Курсы» — карточки лендингов с метками уровня и ссылкой «О курсе»; «Учебные материалы» — библиотека новых курсов и прежние тематические разделы; «Экзамены» — ЕГЭ и ОГЭ. Прежние адреса материалов сохранены. Отдельный верхний пункт Django убран как дублирующий ссылку в материалах. Соцсети доступны текстовыми ссылками в верхней строке, почта — mailto.

Компонент находится в `templates/menuBS4.html`, стили в `base_static/css/site-navigation.css`, поведение в `base_static/js/site-navigation.js`. Подключение — `templates/baseBoot4.html`. Лендинги сохраняют свои отдельные шапки. Общие плагины старого сайта не удалены: они могут использоваться другими компонентами.

Открытие по нажатию через native details/summary: Enter и Space работают без отдельной реализации клавиатуры, без JS доступны все ссылки. С JS открыт один раздел, меню закрывается по Escape, клику снаружи, выбору ссылки и уходу фокуса из шапки. Escape возвращает фокус к кнопке раздела, затем закрывает мобильное меню. Пункт текущей страницы помечается aria-current. На ширине до 800 px меню превращается в мобильные раскрывающиеся разделы с собственной прокруткой.

Проверки: Django tests courses/home; Chromium 1440/1024/801/800/390/320, длинные названия без пересечений, панели в пределах окна, Escape, переключение разделов, клик снаружи, режим без JavaScript. Внешние запросы в браузерной проверке заблокированы. После обновления выполнить обычный collectstatic; миграции и зависимости не нужны.
