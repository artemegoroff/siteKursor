# Редактирование блоков урока

На странице урока блоки можно перетаскивать за заголовок с символом ⠿.
Кнопки ↑ и ↓ перемещают блок на одну позицию и доступны с клавиатуры.
Перенос работает и для новых блоков до первого сохранения.
Изменение порядка применяется только после сохранения урока.

Поле «Тип блока» управляет показом содержимого:

- Текст — TinyMCE.
- Видео — YouTube ID и Rutube ID.
- Практика — ссылка на задания.

Тип и заголовок доступны всегда. При переключении типа скрытые значения не
очищаются и сохраняются вместе с формой. Незавершённая ссылка в неактивном
поле не блокирует текстовый или видеоблок; после выбора «Практика» ссылка
снова проверяется как URL. Ошибки полей остаются видимыми для исправления.

Перед перемещением редактор сохраняет HTML в textarea и восстанавливается
после переноса. То же происходит при удалении нового блока, когда Django
меняет ID следующих форм. Это защищает несохранённый текст TinyMCE.

## Выпуск

Миграции и новые зависимости не требуются. После установки кода выполнить
collectstatic, если сервер обслуживает собранную статику, и обновить страницу
админки с очисткой кеша браузера.

## Проверки

```sh
python manage.py test courses.test_admin_blocks
python manage.py makemigrations --check --dry-run
```

В браузере дополнительно проверить:

1. Показ полей у существующих и новых блоков.
2. Переключение типа туда и обратно без потери введённых значений.
3. Перенос текстового блока с несохранённым форматированием.
4. Перенос ещё не сохранённого блока и удаление соседнего нового блока.
5. Сохранение урока, порядок блоков на сайте и повторное открытие редактора.
6. Пользователю с правом только просмотра кнопки переноса не показываются.
