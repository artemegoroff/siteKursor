# Персональные настройки списка уроков

В списке уроков появилась панель «Настроить таблицу» над действиями. Можно выбрать видимые колонки и редактирование названия, slug и SEO keywords прямо в строках. Название всегда видно. Когда оно редактируется, отдельная ссылка «Открыть» ведёт в полную форму урока; иначе ссылкой является само название.

Модуль и родительский урок доступны только для просмотра в списке. Порядок меняется существующим перетаскиванием; если его колонка скрыта, ручка также скрывается. Полная форма урока остаётся прежней. Настройка списка не меняет разрешения пользователя.

«Применить» сохраняет настройки таблицы для аккаунта, «Сбросить настройки» возвращает исходные колонки и отключает редактирование в списке. Правки уроков сохраняются отдельно стандартной кнопкой «Сохранить». При смене настроек с несохранёнными правками требуется подтверждение их отмены. Фильтры, поиск и страница сохраняются; параметр сортировки o сбрасывается, поскольку он ссылается на индексы изменяемых колонок.

## Реализация

Новая модель LessonListPreference содержит OneToOne-связь с AUTH_USER_MODEL и два JSON-списка. Запись создаётся только при сохранении настроек и удаляется при сбросе. Настройки не регистрируются отдельной админкой. Данные уроков при миграции не меняются.

LessonTablePreferencesMixin настраивает копию ModelAdmin для текущего запроса, не общий экземпляр. Метод ручки adminsortable2 повторно привязывается к копии; исходный обработчик сортировки сохраняется. Поэтому выбранные одним пользователем поля редактирования не переходят к другому пользователю. Для пользователей с правом только просмотра редактирование и ручки сортировки отключены.

Настройки принимаются POST-запросом с CSRF, поле пользователя берётся из request.user, список полей ограничен на сервере. Модуль, родителя и порядок невозможно сделать list_editable подменой запроса. Массовое изменение slug проверяется на конфликты с существующими уроками и между отправляемыми строками одного модуля. При ошибке группа не сохраняется. Одинаковые slug в разных модулях допустимы.

## Проверка и выпуск

61 тест проекта: сохранение настроек и их изоляция, поля формы, постоянная ссылка на урок, массовое сохранение, игнорирование подставленных связей, конфликты slug, фильтры, сброс, права, CSRF, работа сортировки. Браузерная проверка настоящей админки: настройка через чекбоксы, сохранение строк, перезагрузка, предупреждение о несохранённых правках, сброс, реальное перетаскивание с проверкой после перезагрузки и мобильный вид.

После слияния выполнить `python manage.py migrate`, `python manage.py collectstatic --noinput` и перезапустить приложение. Миграция courses.0011 создаёт только таблицу персональных настроек. Новых зависимостей нет.
